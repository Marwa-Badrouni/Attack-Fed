## Overview

Attack-Fed is a federated learning framework designed for intrusion detection under label-space heterogeneity, where participating clients may observe different subsets of attack categories. The framework first characterizes each client's local attack profile using an Attack Category Profile (ACP), then groups clients with similar label-space characteristics using Affinity Propagation. A Cluster Relationship Graph (CRG) is subsequently constructed to identify related client clusters. Attack-Fed leverages class-level prototypes to perform knowledge-guided cross-cluster transfer without sharing raw data or complete model parameters. The transferred knowledge is incorporated into local training through a prototype-based regularization objective, enabling clients to benefit from related attack knowledge while preserving data locality and privacy.
